<h1>README (English + Latvian)</h1>
<h2>English</h2>
<h3>Project name</h3>
Ieteikumi
<h3>Description</h3>
"Ieteikumi" is a small web application that allows users to share, save, and view recommendations.<br>
Users can create an account, log in, and submit suggestions such as foods, activities, or anything they want to recommend.<br>
<h3>Technologies Used</h3>
<ul>
  <li>PHP - backend logic</li>
  <li>HTML/CSS - structure and styling</li>
  <li>JavaScript - front-end interactions & backend</li>
  <li>MySQL - database</li>
  <li>Laragon - local development environment</li>
</ul>
<h3>Features</h3>
<ul>
  <li>User registration and logic</li>
  <li>Create and save recommendations</li>
  <li>View recommendations from other users</li>
  <li>Simple and clean interface for any devices</li>
</ul>
<h3>How to Run</h3>
<ol>
  <li>Install Laragon 6.0 (https://github.com/leokhoa/laragon/releases)</li>
  <li>Clone or download the project folder into your www directory</li>
  <li>Import the SQL file into your database</li>
  <li>Start the server in Laragon</li>
  <li>Open the project in your browser (example: http://localhost/Ieteikumi)</li>
</ol>

<h2>Latviešu</h2>

<h3>Apraksts</h3>
  "Ieteikumi" ir neliela tīmekļa lietojumprogramma, kas ļauj lietotājiem kopīgot, saglabāt un skatīt ieteikumus.<br>
  Lietotāji var izveidot kontu, pieteikties un iesniegt ieteikumus, piemēram, par ēdieniem, aktivitātēm vai jebko citu, ko viņi vēlas ieteikt.<br>
<h3>Izmantotās tehnoloģijas</h3>
<ul>
  <li>PHP - servera loģika</li>
  <li>HTML/CSS - struktūra un stils</li>
  <li>JavaScript - lietotāja saskarnes mijiedarbība un servera atbalsts</li>
  <li>MySQL - datubāze</li>
  <li>Laragon - lokālā izstrādes vide</li>
</ul>
<h3>Funkcijas</h3>
<ul>
  <li>Lietotāja reģistrācija un loģika</li>
  <li>Ieteikumu izveide un saglabāšana</li>
  <li>Skatīt citu lietotāju ieteikumus</li>
  <li>Vienkārša un skaidra saskarne jebkurai ierīcei</li>
</ul>
